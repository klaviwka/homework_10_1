# Проект: Маскировка данных и обработка транзакций

## Цель проекта

Данный проект включает функции для маскировки номеров кредитных карт и счетов, преобразования формата даты, фильтрации и сортировки транзакций, а также генерации описаний транзакций и номеров карт. Дополнительно реализованы инструменты для чтения финансовых данных из CSV и Excel-файлов. Эти функции могут быть полезны для обеспечения безопасности данных пользователей и упрощения работы с финансовыми записями.

## Установка

Для использования данного проекта необходимо иметь установленный Python версии 3.6 или выше. Вы можете установить необходимые зависимости с помощью следующей команды:
bashpip install -r requirements.txt

Или воспользуйтесь менеджером пакетов Poetry:
bashpoetry install


## Использование

### 1. Маскировка номера кредитной карты

Функция `get_mask_card_number` маскирует номер кредитной карты, оставляя видимыми только первые 6 и последние 4 цифры.

### 2. Маскировка номера счета

Функция `get_mask_account` маскирует номер счета, оставляя видимыми только последние 4 цифры.

### 3. Преобразование формата даты

Функция `get_date` преобразует строку с датой из формата `'YYYY-MM-DDTHH:MM:SS.ssssss'` в формат `'DD.MM.YYYY'`.

### 4. Фильтрация транзакций

Функция `filter_by_state` фильтрует список транзакций по значению ключа `'state'`.

### 5. Сортировка транзакций по дате

Функция `sort_by_date` сортирует список транзакций по дате.

### 6. Генерация описаний транзакций

Функция `transaction_descriptions(transactions)` — генератор, который последовательно выдаёт описания транзакций.

- **Параметры:**
  - `transactions`: Список транзакций.
- **Возвращает:**
  - Последовательные описания транзакций.

### 7. Генерация номеров банковских карт

Функция `card_number_generator(start=1, stop=9999999999999999)` генерирует номера банковских карт от `start` до `stop` включительно.

- **Параметры:**
  - `start (int)`: Начальное значение диапазона (включительно).
  - `stop (int)`: Конечное значение диапазона (включительно).
- **Возвращает:**
  - `str`: Следующий номер карты в формате `XXXX XXXX XXXX XXXX`.

### 8. Фильтрация транзакций по валюте

Функция `filter_by_currency(transactions, currency)` фильтрует транзакции по заданной валюте.

- **Параметры:**
  - `transactions`: Список транзакций.
  - `currency`: Код валюты (например, `"USD"`).
- **Возвращает:**
  - Итератор по транзакциям с заданной валютой.

### 9. Чтение данных из CSV-файла

Функция `read_csv_transactions(file_path)` считывает финансовые операции из CSV-файла и возвращает их в виде списка словарей.

- **Параметры:**
  - `file_path (str)`: Полный путь к файлу CSV.
- **Возвращает:**
  - `list of dicts`: Список словарей, представляющих транзакции.

### 10. Чтение данных из Excel-файла

Функция `read_excel_transactions(file_path)` считывает финансовые операции из Excel-файла и возвращает их в виде списка словарей.

- **Параметры:**
  - `file_path (str)`: Полный путь к файлу Excel.
- **Возвращает:**
  - `list of dicts`: Список словарей, представляющих транзакции.

## Тестирование

Для обеспечения корректной работы функций проекта рекомендуется проводить тестирование. В проекте используются модульные тесты, написанные с помощью библиотеки `unittest`, которая входит в стандартную библиотеку Python.

### Запуск тестов

1. Убедитесь, что у вас установлен Python версии 3.6 или выше.
2. Перейдите в директорию проекта в терминале.
3. Запустите тесты с помощью следующей команды:
bashpython -m unittest discover


Или, если вы используете Poetry:
bashpoetry run python -m unittest discover


По умолчанию `unittest` будет искать файлы, начинающиеся с `test_` или заканчивающиеся на `_test.py`, и выполнит все тесты, определенные в этих файлах.

### Структура тестов

Тесты организованы в файлы, начинающиеся с `test_`.
